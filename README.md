# দোকান POS — অফলাইন বিলিং অ্যাপ

এক ফাইলের অ্যাপ। কম্পিউটার আর ফোন — দুই জায়গায় চলে, **ইন্টারনেট ছাড়াই**।
কোনো সার্ভার নেই, কোনো লগইন নেই। দোকানের সব হিসাব দোকানদারের নিজের ডিভাইসেই থাকে।

## ফাইলগুলো কী

| ফাইল | কাজ |
|---|---|
| `index.html` | অ্যাপটা নিজেই — পুরোটা এক ফাইলে |
| `make-copy.html` | **শুধু আপনার জন্য** — দোকানের নাম দিয়ে ওই দোকানের কপি বানায় |
| `sw.js` | নেট ছাড়া চলার ব্যবস্থা |
| `manifest.webmanifest` | ফোনে "হোম স্ক্রিনে যোগ" করার তথ্য |
| `icon-192.png`, `icon-512.png` | অ্যাপের আইকন |

> `make-copy.html` রেপোতে রাখলে যে কেউ নিজের নামে কপি বানিয়ে নিতে পারবে।
> চাইলে ওটা রেপোতে না রেখে শুধু নিজের কম্পিউটারে রাখুন।

## GitHub Pages-এ তোলা

1. GitHub-এ নতুন একটা **public** repository খুলুন (যেমন `dokan-pos`)
2. **Add file → Upload files** — এই ফোল্ডারের সব ফাইল টেনে ছাড়ুন, **Commit**
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, folder: **/ (root)** → **Save**
4. এক-দুই মিনিট পর লিংক তৈরি: `https://<আপনার-ইউজারনেম>.github.io/dokan-pos/`

## দোকানদারকে যা বলবেন

**ফোনে:**
1. লিংকটা খুলুন (Chrome-এ)
2. উপরে ডানে ⋮ → **"Add to Home screen"** / **"হোম স্ক্রিনে যোগ করুন"**
3. এরপর আইকনে চাপলেই খুলবে — **নেট লাগবে না**

**কম্পিউটারে:** লিংকটা খুলে bookmark করে রাখুন। অথবা HTML ফাইলটা ডেস্কটপে রেখে ডাবল ক্লিক।

## জরুরি কথা — দোকানদারকে বলে দেবেন

- **ফোন আর কম্পিউটার আলাদা খাতা।** একটাই ডিভাইস বেছে নিতে হবে।
- **সপ্তাহে একবার ব্যাকআপ নামাতে হবে** (সেটিংস → ব্যাকআপ → ব্যাকআপ নামান),
  আর ফাইলটা নিজের WhatsApp-এ নিজেকে পাঠিয়ে রাখতে হবে।
  ব্রাউজারের ক্যাশ ক্লিয়ার করলে বা ব্রাউজার বদলালে হিসাব মুছে যেতে পারে —
  ব্যাকআপ থাকলে ফিরিয়ে আনা যায়, না থাকলে যায় না।

## ভিতরে যা আছে

**বাকি** — নিজের আলাদা পাতা: নম্বর লিখলেই মানুষ, তার মোট বাকি, কত দিনের পুরাতন,
পুরো খাতা (কবে কত বাকি নিল, কবে কত শোধ করল, প্রতি লাইনে অবশিষ্ট),
এক চাপে টাকা জমা / WhatsApp তাগাদা / SMS / কল, আর পুরো তালিকা এক্সেলে ·
বিক্রয় (ছাড়, ট্যাক্স, ক্যাশ+বিকাশ ভাগ, বিল হোল্ড) · পণ্য ও স্টক (ছবিসহ, বারকোড লেবেল) ·
কাস্টমার · সাপ্লায়ার ও বাকিতে মাল কেনা ·
দৈনিক/মাসিক/বার্ষিক রিপোর্ট (এক্সেলে নামে) · লাভ-খরচ-দিন শেষের ক্যাশ মিলানো ·
মোবাইল ব্যাংকিং এজেন্ট খাতা · দৈনিক/মাসিক টার্গেট · এক ডিভাইসে কয়েকটা দোকান ·
বাংলা/ইংরেজি · দিন/রাত/নিজে থেকে · ৮ রকম থিম · ৪ রকম লেখার সাইজ · ঘন/আরামদায়ক ভিউ ·
"অ্যাপ বসান" বাটন (হোম স্ক্রিনে আইকন)

বাংলা ফন্ট (Hind Siliguri) অ্যাপের ভিতরেই বসানো — যে ফোন বা পিসিতেই খুলুক,
লেখা একই রকম দেখাবে, নেট লাগবে না।

## আপডেট দিলে

`index.html` বদলে আবার upload করুন। `sw.js` এর ভিতরে `pos-v3` কে `pos-v4` করে দিন —
তাহলে সবার ফোনে নতুন সংস্করণ পৌঁছাবে।
